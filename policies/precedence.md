# Precedence

Resolve instructions from highest to lowest:

1. Runtime and platform constraints.
2. LES principles and this precedence policy.
3. Universal LES rules.
4. Selected profile rules.
5. Project decisions and repository conventions.
6. Project-supplied team governance.
7. Active task scope and work state.

A lower level may narrow behavior but cannot weaken a higher level. When two
active instructions cannot be reconciled, stop dependent work, name both
instructions, and request a human decision.
