# Context Loading

**Activate:** every task.

Load the kernel, project entrypoint, active work state, and only the rule,
workflow, profile, and code paths needed for the task. Follow pointers when their
trigger matches. Expand context when evidence reveals a boundary; avoid loading
whole repositories or catalogs without a concrete question.

Start with a compact context trace: loaded authority, selected route, risk floor,
active profile, and evidence target. Keep always-loaded pointers short; disclose
branch-specific reference behind a trigger. When context pressure would hide
steps or evidence, split the sequence at a real handoff or subagent boundary and
record what was deliberately deferred.
