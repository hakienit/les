# LES

This repository uses the user-local LES installation at `~/.les-agents`.
Use that installation as the only LES source for this repository.

Read the adapter matching the current AI CLI:
- codex: ~/.les-agents/adapters/codex/AGENTS.md
- claude-code: ~/.les-agents/adapters/claude-code/CLAUDE.md
- gemini-cli: ~/.les-agents/adapters/gemini-cli/GEMINI.md
- antigravity: ~/.les-agents/adapters/antigravity/agent.md

Then read `~/.les-agents/skills/les-bootstrap/SKILL.md` before starting work.
