# Frontend Profile

This profile is the primary LES capability track for frontend developers. It adds
framework-neutral web-interface constraints without choosing a framework or
component library. Load only the rules relevant to the task through the frontend
router and its selected specialist skills.

`activation.json` defines positive and negative activation triggers. Accessibility,
interaction/responsive behavior, and frontend verification stay active for every
user-interface change; design, experience, and performance rules activate when
their touchpoint is present.
