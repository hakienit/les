# Accessibility

Use semantic structure, keyboard-operable interactions, visible focus, associated
labels, meaningful names, and announced dynamic status. Treat 4.5:1 text contrast
as the default evidence threshold, preserve logical reading and focus order, and
keep every task possible without hover or pointer precision.

Icon-only controls require an accessible name. Decorative media is hidden from
assistive technology; informative media has useful alternative text. Dynamic
loading, success, error, and validation states expose their status to assistive
technology without stealing focus.
