# Interaction and Responsive Behavior

Design mobile-first and preserve the same task outcome at every supported
viewport. Interactive targets are at least 44x44 CSS pixels with visible spacing;
hover is an enhancement, never the only path. Every asynchronous action exposes
pending, success, and recoverable failure feedback.

Avoid horizontal overflow, disabled zoom, hidden focus, and layout changes that
move the user's active target. Respect reduced-motion preferences and use motion
to explain state or spatial continuity. Record the viewport matrix and the
interaction evidence required for the journey.
