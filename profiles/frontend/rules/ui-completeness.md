# UI Completeness

Every user journey defines loading, empty, success, error, disabled, retry, and
permission states where applicable. Preserve user input across recoverable errors
and make destructive consequences clear before commitment. Forms have visible
labels, field-level guidance, nearby errors, and an intentional focus target.
Navigation has a predictable back path and deep-link behavior when the product
supports sharing or reload. Data visualizations provide a legend, text alternative,
or equivalent non-color explanation.
