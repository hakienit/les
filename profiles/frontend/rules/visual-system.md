# Visual System

Match product purpose before selecting a visual direction. State one focal concept
and the review surface before treatment work. Use semantic color tokens, a readable
type scale with a 16px-or-larger body baseline unless the project proves otherwise,
comfortable line height, consistent spacing, and one coherent icon family. Prefer
SVG or the project's approved icon source over emoji or ad hoc glyphs.

Record typography, color, layout, icon, elevation, and motion decisions at the
design boundary. Keep dark-mode, contrast, focus, disabled, error, mobile, and
reduced-motion treatments intentional rather than relying on accidental browser
defaults. Read `../references/design-quality-bar.md` for the visual evidence gate.
